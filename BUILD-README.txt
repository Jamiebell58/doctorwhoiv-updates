Doctor Who IV experimental 0.2.3 cross-build, source-only.

Contains code for automatic doorway threshold entry, optional dynamic rotor objects, and legacy-archive fallback; preserves the 0.2.2 waypoint landing logic at SOURCE level.

This is for running the GitHub Actions compiler, not a gameplay-ready update.
New dynamic rotor WDR geometries are NOT included in this package and cannot be created by the ASI compiler. Without them, the rotor animation stays disabled; other behaviours remain UNTESTED in GTA IV. Do not overwrite a working game installation just because compilation succeeds.

Only code and workflow files will be pushed to the BRANCH dwiv-chatgpt-rotor-walkin-build of Jamiebell58/doctorwhoiv-updates. The repository's default branch and releases are not modified.
